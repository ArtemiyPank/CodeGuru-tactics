# CodeGuru Tactics

## About the CodeGuru Competition

CodeGuru is an annual programming competition focused on creating viruses and warrior programs using 8086 assembly language. Participants write code that competes for survival in computer memory, employing techniques such as self-replication, enemy detection, and destruction. This is very similar to CoreWars, where programs attempt to occupy as much memory as possible and eliminate opponents within a simulated environment. The competition emphasizes creativity, optimization, and strategic thinking in low-level programming.

For more information, visit the official website: [https://codeguru.co.il/Xtreme/](https://codeguru.co.il/Xtreme/)
